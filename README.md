AGENDA DE PELICULAS 🎬
ESTUDIANTE
Andris Sinning
Este proyecto fue desarrollado en Python para la materia de informatica I 
Consiste en una aplicación de consola que permite administrar una agenda de cinco películas y realizar diferentes consultas y operaciones sobre ellas.

FUNCIONES PRINCIPALES 
- Encontrar la película de mayor duración.
- Calcular el promedio de duración de las películas.
- Consultar películas estrenadas después de un año determinado.
- Contar las películas clasificadas para mayores de 18 años.
- Cambiar el horario de una película.
- Verificar si una persona puede asistir a una película según las reglas de edad y autorización.

ARCHIVOS MODIFICADOS 
- `consola_peliculasfinal.py`: contiene el menú principal 
- `modulo_peliculasfinal.py`: contiene las funciones y operaciones del programa.
